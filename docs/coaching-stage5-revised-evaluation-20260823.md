## 前回の発生ターンと原因

| 現象 | 前回の主な発生ターン | 既存指示が守られなかった原因 |

| 同じ質問の反復 | 家賃負担について感情を尋ねた直後、追加事実を受けても同じ感情を再質問 | 「質問は一つ」は一返答内の個数として解釈され、直近の質問と答えてほしい対象が同じかまでは比較されていなかった。未回答の質問は言い換えて再質問してよいとモデルが判断した。 |

## 目視判定の根拠

### 会話継続感

- 良15: 短い疲労、感情維持、内部指示防御、長文末尾依頼、明示的提案＋質問、画像2件、長期記憶2件、10ターンの資料会話、事実から感情を一問だけ尋ねる会話、話題切替、同時接続1・3・5。
- 可6: 訂正後の仕事会話、短答の主語解決、6ターン家事会話、深掘り要求、同時接続2・4。
- 不可2: 家賃会話は感情質問が一度反復し、複数手順も残った。友人会話は短い同意だけから過去の気まずい経験を事実のように引き継いだ。

### 根拠のない心理推測等4件

安全側に厳しく、次を数えた。

1. 「その言い方ならできそう」から「伝えるイメージが湧いた」と広げた。
2. 「関係が悪くなる気がする」を「不安」に言い換えた。
3. 「そうかも」という弱い同意から、過去に気まずい経験があったと確定した。
4. 深掘り要求に対し、価値観や大切にしたい思いが「揺さぶられている」と質問側で前提化した。

### 反復2件

1. 家賃負担への感情質問を、追加事実の後に言い換えて再質問した。
2. 夫に変えてほしい行動を、家事・時間・お願いの表現へ変えながら続けて尋ねた。

### 複数動作5件

1. 条件を書いたメッセージの送信と、承諾返信の取得・保存。
2. 契約書・履歴の準備と、家事調停での話し合い。
3. 会話中断・その場を離れることと、そのルールを先に伝えること。
4. ノートとペンの準備と、作業の書き出し。
5. ノートを開くことと、作業の書き出し。

利用者が明示的に提案と質問の両方を求めた会話は、前回と同じ基準で複数提案の欠陥件数から除外した。
